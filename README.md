# Golden Beach Resort: เว็บไซต์และระบบจองบ้านพัก

FastAPI + Jinja2 + SQLAlchemy เขียนเองทั้งหมด ไม่ใช้ CSS/JS framework และ self-host ฟอนต์ (Chonburi + IBM Plex Sans Thai Looped)
อ่านแผนและเหตุผลการออกแบบได้ที่ `PLAN.md`

## ทดลองบนเครื่อง Windows (ดับเบิลคลิกได้เลย)

| ไฟล์ | ทำอะไร |
|---|---|
| `start.bat` | เปิดเว็บและเปิดเบราว์เซอร์ให้อัตโนมัติ ครั้งแรกจะติดตั้งทุกอย่างเอง (ต้องต่ออินเทอร์เน็ต 1–3 นาที) |
| `stop.bat` | ปิดเว็บให้สมบูรณ์: สั่งให้เว็บปิดตัวเองอย่างปลอดภัยก่อน ถ้าค้างจึงบังคับปิด และรวมไฟล์ฐานข้อมูลให้เรียบร้อย |
| `restart.bat` | ปิดแล้วเปิดใหม่ (ใช้หลังแก้โค้ด) |
| `status.bat` | ดูว่าเว็บเปิดอยู่ไหม พร้อม log ล่าสุด |
| `start-lan.bat` | เปิดให้มือถือ/แท็บเล็ตที่ต่อ Wi-Fi เดียวกันเข้าทดสอบได้ ใช้เช็ค Responsive บนเครื่องจริง |
| `backup.bat` | สำรองฐานข้อมูลและรูปที่อัปโหลดเป็นไฟล์ zip ในโฟลเดอร์ `backups` |
| `reset-demo.bat` | สำรองข้อมูลเดิม แล้วล้างทิ้งและสร้างข้อมูลตัวอย่างชุดใหม่ |
| `run-tests.bat` | รันชุดทดสอบอัตโนมัติ 44 รายการ |
| `setup.bat` | ติดตั้งหรือซ่อมการติดตั้ง (start.bat เรียกให้เองตอนครั้งแรก) |
| `choose-python.bat` | ดู Python ทุกตัวในเครื่องพร้อมผลทดสอบ แล้วเลือกเองว่าจะใช้ตัวไหน (สร้าง .venv ใหม่ ข้อมูลไม่หาย) |

- **เลือก Python อัตโนมัติ:** ค้นหาทุกตัวในเครื่อง (py launcher, registry, โฟลเดอร์ติดตั้งปกติ, PATH) ทดสอบทีละตัว แล้วเลือกตัวที่ดีที่สุด: 3.12 ก่อน (ตรงกับเซิร์ฟเวอร์จริง) แล้ว 3.13, 3.11, 3.14, 3.10 ตัดตัวที่ใช้ไม่ได้ออก (32-bit, free-threaded, ตัวเชื่อม Microsoft Store, venv ของโปรเจกต์อื่น) และลดอันดับตัวที่มีคำเตือนตอนเริ่มทำงาน ถ้าต้องการบังคับใช้ตัวใดตัวหนึ่ง: `set GB_PYTHON=C:\path\python.exe`
- ต้องมี Python 3.10 ขึ้นไป ถ้าไม่มี `setup.bat` จะเสนอให้ติดตั้งผ่าน winget หรือเปิดหน้าดาวน์โหลดให้
- ทุกอย่างติดตั้งในโฟลเดอร์ `.venv` ของโปรแกรมเท่านั้น ไม่กระทบโปรแกรมอื่นในเครื่อง ถ้าต้องการถอนการติดตั้ง ให้ลบโฟลเดอร์โปรแกรมได้เลย
- ถ้าพอร์ต 8000 ถูกโปรแกรมอื่นใช้อยู่ ให้เปิด Command Prompt ในโฟลเดอร์นี้ แล้วพิมพ์ `set PORT=8080` ตามด้วย `start.bat`
- `stop.bat` ปิดเฉพาะเว็บนี้ ไม่ปิดโปรแกรมอื่นที่บังเอิญใช้พอร์ตเดียวกัน
- ข้อมูลทดลองอยู่ในไฟล์ `resort.db` และ log อยู่ที่ `logs\server.log`

### แก้ปัญหาที่พบบ่อย (Windows)

| อาการ | สาเหตุและวิธีแก้ |
|---|---|
| `No time zone found with key Asia/Bangkok` | Windows ไม่มีฐานข้อมูลโซนเวลาในตัว แก้แล้วในเวอร์ชันนี้ (ติดตั้ง `tzdata` และมีค่าสำรอง UTC+7) แค่ดับเบิลคลิก `start.bat` ระบบจะติดตั้งส่วนที่ขาดให้เอง |
| `Could not find platform independent libraries <prefix>` | ข้อความเตือนจาก Python ไม่ใช่ error ของโปรแกรม มักเกิดจากโปรแกรมอื่นตั้งค่า `PYTHONHOME`/`PYTHONPATH` ไว้ในเครื่อง ไฟล์ .bat จะล้างค่านี้ก่อนรันทุกครั้ง และ `setup.bat` จะบอกว่าตั้งค่าไว้ที่ไหน |
| เปิดเว็บไม่ขึ้น | รัน `status.bat` ดู log หรือเปิด `logs\server.log` และ `logs\error.log` |
| ติดตั้งค้างหรือพัง | ลบโฟลเดอร์ `.venv` แล้วรัน `setup.bat` ใหม่ (ข้อมูลใน `resort.db` ไม่หาย) |

`setup.bat` จะตรวจระบบทุกข้อหลังติดตั้งเสร็จ (Python, ไลบรารี, โซนเวลา, โหลดโปรแกรมได้ครบ, เขียนไฟล์ได้, ไฟล์ครบ) ถ้ามีปัญหาจะบอกวิธีแก้ทันที แทนที่จะไปเจอตอนเปิดเว็บ

## รันด้วยคำสั่ง (macOS / Linux)

```bash
pip install -r requirements-dev.txt
python -m app.seed --demo        # ฐานข้อมูล SQLite + บ้าน 9 หลัง + โปร + ข้อมูลตัวอย่าง
uvicorn app.main:app --reload
```

- เว็บภาษาไทย: http://localhost:8000 และภาษาอังกฤษ: http://localhost:8000/en
- หลังบ้าน: http://localhost:8000/admin เข้าด้วย `owner` / `golden1234` ข้อมูลตัวอย่างมีบัญชี `manager`, `fah`, `boy` (ฝ่ายขาย) และ `maid` (แม่บ้าน) รหัสผ่านเดียวกัน
- รัน test: `python -m pytest -q` มี 44 tests ครอบคลุมทุกหน้าและทุกปุ่มในหลังบ้าน ทดสอบผ่านทั้งบน SQLite และ PostgreSQL

## ขึ้นโฮสต์ฟรี (Render + Supabase + ตัวปลุก cron) ค่าใช้จ่าย 0 บาท

ใช้ฐานข้อมูล Supabase แทน Postgres ของ Render เพราะ Postgres ฟรีของ Render ลบทิ้งหลัง 30 วัน และดิสก์ของ Render ฟรีจะล้างทุกครั้งที่ restart ระบบนี้จึงเก็บสลิปและรูปที่อัปโหลดไว้ในฐานข้อมูล (`STORAGE=db`) ข้อมูลจึงไม่หาย

1. **Supabase** (supabase.com): สร้างโปรเจกต์ใหม่ เลือก region Singapore แล้วไปที่ Connect > **Session pooler** คัดลอก URI (`postgresql://...`) ไว้
2. **GitHub**: push โฟลเดอร์นี้ขึ้น repository
3. **Render** (render.com): New > Blueprint > เลือก repo ระบบจะอ่าน `render.yaml` เอง แล้วกรอกค่าเหล่านี้
   - `DATABASE_URL` = URI จากข้อ 1
   - `PUBLIC_BASE_URL` = `https://<ชื่อ>.onrender.com` (หรือโดเมนจริงของรีสอร์ท)
   - `ADMIN_PASSWORD` = รหัสผ่านเจ้าของ
   - `SECRET_KEY` และ `CRON_TOKEN` ระบบสร้างให้อัตโนมัติ
4. **ตัวปลุก**: Render ฟรีจะหลับหลังไม่มีคนเข้าเว็บ 15 นาที (ตื่นช้าประมาณ 1 นาที) และ Supabase ฟรีจะหยุดโปรเจกต์ถ้าไม่มีการใช้งาน 7 วัน
   ตั้ง cron-job.org (ฟรี) ให้เรียก `https://<เว็บ>/cron?token=<CRON_TOKEN>` ทุก 10 นาที (หรือใช้ `.github/workflows/cron.yml` ที่ให้มา) จะได้ทั้งเว็บไม่หลับ ระบบปล่อยห้องที่หมดเวลาชำระตรงเวลา และปฏิทิน Airbnb อัปเดต
   Render ให้ใช้ฟรี 750 ชั่วโมงต่อเดือน พอสำหรับเปิดเว็บเดียวตลอดเดือน
5. เข้า `/admin` แล้วเปลี่ยนรหัสผ่าน จากนั้นไปที่ ตั้งค่าระบบ ใส่เลขพร้อมเพย์, LINE token, Brevo API key (อีเมล) และค่า Search Console

คู่มือแบบละเอียดทีละขั้น: ดูเอกสาร "คู่มือตั้งค่าและขึ้นโฮสต์ฟรี" ที่ส่งให้

โฮสต์อื่นที่ใช้ `Dockerfile` ได้ทันที: Koyeb, Fly.io, Google Cloud Run, Hugging Face Spaces หรือ VPS ของตัวเอง

## ระบบอัตโนมัติ (ช่วยแอดมิน)

ระบบทำงานเองทุก 5 นาที และทุกครั้งที่ `/cron` ถูกเรียก ทุกข้อเปิด/ปิดได้ที่ ตั้งค่าระบบ > ระบบอัตโนมัติ และไม่มีวันส่งซ้ำ (บันทึกไว้ในตาราง `automation_logs`)

| เมื่อไร | ระบบทำอะไร |
|---|---|
| แอดมินอนุมัติคำขอ | ปฏิเสธคำขออื่นที่ชนวันบ้านหลังเดียวกันทันที พร้อมอีเมลเสนอบ้านที่ยังว่างและลิงก์จอง |
| เหลือเวลากันห้องน้อย | อีเมลเตือนลูกค้า + แจ้ง LINE/กระดิ่งแอดมินเจ้าของเคส |
| หมดเวลาชำระ | ปล่อยห้อง (มีอยู่แล้ว) + อีเมลบอกลูกค้า ถ้าบ้านยังว่างแนบลิงก์จองใหม่ |
| คำขอ/สลิปค้างเกิน 30 นาที | ทวงในกลุ่ม LINE (🟠) และทวงซ้ำเมื่อค้างเกิน 2 ชั่วโมง (🔴) |
| ลูกค้าแนบสลิปที่เคยใช้แล้ว | เตือน "สลิปซ้ำ" ในกลุ่ม LINE และหน้าการจอง |
| ก่อนเข้าพัก 1 วัน | อีเมลวิธีเดินทาง แผนที่ เวลาเช็คอิน กฎบ้าน ยอดคงเหลือ |
| เลยเวลาเช็คเอาท์ 1 ชม. | เช็คเอาท์ให้ บ้านเป็น "รอทำความสะอาด" แจ้งแม่บ้าน |
| หลังเช็คเอาท์ | อีเมลขอบคุณ + ลิงก์รีวิว (ใส่ลิงก์ Google Review ในตั้งค่า) |
| ทุกเช้า (07:30) | สรุปงานวันนี้เข้ากลุ่ม LINE: เข้า/ออก บ้านว่างคืนนี้ บ้านรอทำความสะอาด งานค้าง |
| ฟอร์มติดต่อ/ขอใบเสนอราคาเหมา | ตอบอีเมลทันที คำขอเหมาบอกเลยว่าวันนั้นว่างทั้งรีสอร์ทหรือไม่ พร้อมราคาแพ็กเกจ |
| ทุกวันที่ 1 | สรุปยอดค่าคอมรอจ่ายให้ทุกคน (เจ้าของกด "จ่ายแล้ว" หลังโอน) |
| ใส่รหัสผิด 5 ครั้งใน 15 นาที | ล็อกบัญชีนั้น 15 นาที (IP เดียวผิด 20 ครั้งก็ล็อก) |

หน้าใหม่สำหรับแอดมิน: **เช็กลิสต์วันนี้** บนหน้าภาพรวม (ตรวจสลิป, ตอบคำขอ, รอเช็คอิน, เลยเวลาเช็คเอาท์, บ้านยังไม่พร้อมทั้งที่มีแขกเข้า, ค่าที่ยังไม่ได้ตั้ง) และ **เช็คว่าง / ตอบแชท** (`/admin/quick`) ใส่วันที่และจำนวนคน ได้รายการบ้านว่างพร้อมราคาโปรโมชั่นจริง และข้อความตอบลูกค้าที่คัดลอกไปวางใน LINE/Facebook ได้ทันที

อีเมลถึงลูกค้าต้องตั้ง **Brevo** (ฟรี 300 ฉบับ/วัน ส่งผ่าน HTTPS จำเป็นบน Render ฟรีเพราะ Render ฟรีปิดพอร์ต SMTP) หรือ SMTP เมื่อใช้โฮสต์อื่น (เช่น Gmail + App Password: host `smtp.gmail.com` port 587) ข้อความกลุ่มต้องตั้ง LINE Messaging API ถ้ายังไม่ตั้ง ระบบยังทำงานและแสดงในกระดิ่งแทน

## รับชำระออนไลน์ ยืนยันการจองอัตโนมัติ (Opn Payments)

ช่องทางที่มีให้ลูกค้าเสมอ: QR พร้อมเพย์พร้อมยอดเงิน (ใส่เลขพร้อมเพย์ในตั้งค่า) และโอนเข้าบัญชีแล้วแนบสลิป แอดมินกด "ยอดถูกต้อง ยืนยัน" แล้วระบบยืนยันการจองให้

ถ้าต้องการให้ **เงินเข้าแล้วยืนยันเองโดยไม่ต้องตรวจสลิป** ให้เปิดบัญชีร้านค้า [Opn Payments](https://www.opn.ooo) (เดิมชื่อ Omise มีค่าธรรมเนียมต่อรายการตามสัญญา) แล้ว:
1. ตั้งค่าระบบ > รับชำระออนไลน์: ติ๊กเปิด ใส่ Public key (`pkey_...`) และ Secret key (`skey_...`) ใช้คีย์ทดสอบ (`pkey_test_`) ลองก่อนได้
2. ในแดชบอร์ด Opn ตั้ง Webhook เป็น `https://<เว็บ>/payments/opn/webhook`
3. หน้าชำระเงินของลูกค้าจะมีปุ่ม **พร้อมเพย์ QR** (สแกนจ่ายแล้วหน้าเว็บยืนยันเองภายในไม่กี่วินาที) และ **บัตรเครดิต / Mobile Banking** (K PLUS, SCB, กรุงศรี, กรุงเทพ, กรุงไทย ตามที่บัญชี Opn เปิดให้)

ระบบไม่เชื่อข้อมูลที่ส่งเข้ามา ทุกครั้งจะถามสถานะจาก Opn ด้วย Secret key เองก่อนบันทึกเงิน จึงปลอม webhook ไม่ได้ และบันทึกเงินครั้งเดียวแม้ webhook มาซ้ำ ส่วนนี้ทดสอบด้วยการจำลอง API ของ Opn แล้ว ก่อนเปิดใช้จริงให้ลองด้วยคีย์ทดสอบของบัญชีจริง 1 รอบ

## สำรองข้อมูล

เจ้าของเข้า ตั้งค่าระบบ > **ดาวน์โหลดไฟล์สำรอง** ได้ไฟล์ zip เดียวที่มีทุกตาราง (รวมรูปและสลิป) กู้คืนด้วย
`python -m app.backup restore <ไฟล์>.zip --replace` โดยตั้ง `DATABASE_URL` ชี้ฐานปลายทางก่อน (บน Windows ต้อง `pip install "psycopg[binary]"` ใน .venv)

LINE: ตั้ง Webhook URL ใน LINE Developers เป็น `https://<เว็บ>/line/webhook` และใส่ Channel secret ในตั้งค่า แล้วเชิญบอทเข้ากลุ่ม ระบบบันทึก Group ID ให้เอง

## SEO และการค้นหาด้วย AI

ระบบทำไว้ให้แล้ว:
- **URL แยกภาษา**: `/` (ไทย) และ `/en/...` (อังกฤษ) มี `hreflang` และ canonical ทุกหน้า
- **title / description** เฉพาะของแต่ละหน้า ใส่คำค้นจริง เช่น "ที่พักติดทะเลนาจอมเทียน", "ใกล้ Tutu Beach", "เหมารีสอร์ท"
- **Structured data (JSON-LD)**: Resort (ที่อยู่ พิกัด เบอร์ ราคา เวลาเช็คอิน สัตว์เลี้ยง สิ่งอำนวยความสะดวก), WebSite, บ้านแต่ละหลัง (Accommodation + Offer ราคา), BreadcrumbList และ FAQPage
- **หน้า FAQ** (`/faq`) ตอบคำถามที่ลูกค้าถามบ่อย ข้อมูลดึงจากระบบจริง ราคาจึงไม่ล้าสมัย AI search engine ชอบดึงหน้าแบบนี้ไปตอบ
- **`/llms.txt`** สรุปข้อมูลรีสอร์ทเป็นข้อความล้วนสำหรับ AI assistant ตามมาตรฐาน llmstxt.org
- **`/robots.txt`** อนุญาต Googlebot, Bingbot และบอทของ AI search ทุกเจ้า (OAI-SearchBot/ChatGPT, Claude-SearchBot, PerplexityBot, Google-Extended, Applebot ฯลฯ) และกันหน้า admin/การจองไว้
- **`/sitemap.xml`** ครบทุกหน้าทั้งสองภาษา พร้อม hreflang และรูป
- Open Graph สำหรับแชร์ลง Facebook/LINE, หน้าเว็บ render ฝั่งเซิร์ฟเวอร์ (บอทอ่านได้ครบโดยไม่ต้องรัน JS), รูป WebP, gzip และ cache
